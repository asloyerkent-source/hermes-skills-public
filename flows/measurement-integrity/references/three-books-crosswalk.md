## 一、三书共同指认的核心错误：自己批准自己的提案

三本从三个角度指向同一件事，实现层各不相同：

- **bojieli（ch9 loop-engineering）**：「模型可以提出完成，但不能批准自己的完成」——
  只有通过独立验证的结果才能写入持久进度；审核者必须读**独立证据**。
  「路由结果只是更新提案，尚未获得发布资格。」
- **ace-skills（self-improvement-loops）**：「The Loop Is Not the Intelligence」——
  递归结构**双向放大**基座模型质量：强模型上复利增益，弱模型上跨迭代拉低平均表现。
  硬判据是**环外不变量**：评估器、其插桩、权限控制、预算强制，必须住在
  **循环能修改的范围之外**；「每一个有记录的 reward hack 都破坏了这一条」。
- **hello-agents（ch8）**：记忆生命周期含 `forget` 环节，缺失则记忆只增不减。

→ 已落 `measurement-integrity` 铁律 23（环外不变量）/ 24（可归因输出）。

## 二、循环退化的识别指纹

> ace-skills：「一个坏掉的改进器**静默返回未修改的输入**，在聚合指标上看起来就像稳定。」

三种表现同源：停更很久没人发现、watchdog 持续报假成功、扫描器长期少扫一部分对象。
**判据：任何「自改进」产物若在 N 个周期内输出逐字相同，先假设它哑了，
用铁律 22 的三态验证注入一个已知坏态。**

## 三、约束写在文本里 ≠ 约束被强制执行

> ace-skills：「在提示词文本里陈述的约束**会被演化掉**。预算、权限、沙箱边界必须在
> **运行时**强制执行，绝不能放在可变的提示词或 harness 代码里。」

写进 yaml / md / prompt 但没有任何代码读它 = 闭环没有开启，而读者会以为开启了。
**判据：每条「已配置的约束」都要能指出读它的那个函数名；指不出来就是装饰。**

## 四、记忆：判据不能是存储约束

三本一致否定「还剩多少字符」作为主判据：

- **bojieli（ch3）**：「不写什么」由**访问频率、时间衰减、情感强度、信息独特性**决定。
  并点名**全量替换是退化形态**：「反复让模型重写整份记忆……旧版本中的少数重要细节
  可能在多轮改写后逐渐消失」；ACE 的正解是**带稳定标识符的条目集合 + 增量更新**。
- **hello-agents（ch8）**：遗忘三策略 = **重要性 / 时间 / 容量**。
  **容量排第三**，且触发时删「最不重要」而非「最旧的」。
  另有 `consolidate`（working → episodic → semantic 晋升链）—— 整合环节，
  缺了它记忆只会增长。
- **ace-skills（memory-systems）**：持久语义记忆 + **时序有效性**
  （记录在什么时间区间内为真）。

**最有用的一句自检**：你说不清某条记忆为什么该留，就说明没有重要性判据。

## 五、技能路由：description 是唯一路由信号

- **bojieli（ch2）**：description 应「明确写出**何时使用**和**何时不使用**的边界，
  并给出**几条典型反例**」；「描述太宽泛……等于任何相关工作都能触发，路由就会失准」；
  「何时该用我」比「我能做什么」重要得多。
  **旁证：作者自带的 skill description 全是 150–200 字长句。**
- 规模分档（ch4）：十几 → 全量常驻；几十 → 只暴露索引；上百 → 检索预筛选；
  上千 → 主动发现。
- **形态与披露是两个独立决策**：「别把两者混为一谈」「别把全量常驻当默认」。
- 陷阱：「只做索引不做检索，也不做层次化组织，**索引本身长得和全量列表一样**」。

**推论**：给 description 设字符上限会**从设计上禁止**负边界与反例，
于是路由只能靠正向触发词猜 —— 表现是同一句话反复改措辞却改不动。

## 六、三书之间真实存在的冲突（不要拼成大全）

| 争点 | bojieli | ace-skills | hello-agents |
|---|---|---|---|
| 容量压力下怎么办 | 按访问频率/衰减/独特性筛 | —— | 容量策略是 forget 的一种，删「最不重要」 |
| 记忆更新形态 | 增量 + 定期整理 | 时序有效性 | 晋升链 consolidate |
| 环外不变量 | 提案须独立验证 | 评估器须搬出可写范围 | —— |

按各自适用面分开用，冲突处（本文件表格即冲突清单）回到具体场景再定，
不要预先合成一份「记忆管理大全」。

## 七、怎么用这三本

1. **先读自己系统的对应技能**（`measurement-integrity` / `hermes-memory-ops` /
   `skill-library-curation`），判据已落进铁律。
2. 需要展开时再回原文取，vault 路径见上。
3. **不要用关键词匹配判断「我有没有对应」**—— 同名不等于查过了（铁律 19）。
